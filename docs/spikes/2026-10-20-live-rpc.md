Endpoint: https://api.mainnet.solana.com, 8 rps / 3.5 rps per method. Run with `pnpm --filter @pumpfun/api smoke <MINT>`.

| Token | Mint | createTxFound | Funding chain | Cold time | Notes |

| Fartcoin (old, migrated, very active) | `9BB6…pump` | yes | dev is `high_activity` (stops at hop 0) | 278 s, then ~100 s after the concurrency fix (est.) | 84 s spent walking the bonding curve history |
| Befreit die Katze (fresh, `create_v2`, Token-2022) | `DvTM…pump` | yes | signer is `high_activity`, creator is `unknown_origin` | 106 s | signer ≠ creator: launched through a third-party tool |

## Findings

- **Event prefix.** Anchor writes `sha256("anchor:event")[..8]` as a little-endian u64, so the on-chain prefix is the hash reversed (`e445a52e51cb9a1d`). Caught by the unit test before any live call. Event discriminators (`CreateEvent`, `TradeEvent`) match the official IDL.
- **Real transactions decode.** Trade and create events from live `create` and `create_v2` transactions decode correctly, including Token-2022 tokens.
- **Transaction version 1 exists on mainnet.** `getTransaction` fails with "Transaction version (1) is not supported" unless `maxSupportedTransactionVersion: 1` is passed. Fixed in `RpcChainSource`.
- **Mint history is unbounded.** Fartcoin's mint has far more than 20 pages of signatures, and its legacy bonding curve has no `creator` field, so the first version could not find the dev at all. Walking the **bonding curve account** instead works: after migration all trading moves to PumpSwap and the curve's history stops growing. Fixed in `resolveToken` (`curveMaxPages: 40`).
- **Sequential fetches were latency bound.** 60 dev transactions took 190 s (~0.3 tx/s, far under the 3.5/s budget). Dev transactions are now fetched 4 at a time; the pool still enforces the rate.
- **Sells older than the scan window.** Fartcoin's dev holds 0 of a 67M initial buy, but all sells predate the 60-tx scan, so "released" showed 0%. Released now also counts the shortfall between what the dev acquired and what it holds.
- **Launchpad tools.** Some launches are signed by a bot wallet with the user passed as `creator`. Both wallets are traced; dev history now matches either `user` or `creator`.
- **Busy wallets are common.** Both deployers in this sample exceed 5,000 transactions and stop as `high_activity`. Expected for famous devs and launch bots; the creator chain still gives a trail.
- **Network flakiness.** DNS lookups for the RPC host failed intermittently from background processes; retries with backoff handle short blips, longer outages fail the token step with a clear error.
- **Old transactions** (2024) were served by public RPC without problems.
- **Padded names.** Some tokens have trailing spaces in name/symbol; decoder now trims them.

## Spec changes needed

- Creation tx lookup uses the bonding curve account (spec 6.1 step 3 said the mint).
- RPC must request transaction version 1.
