# Live Screener Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/screener` page listing every new pump.fun token live (age, market cap, curve progress, flags, risk score), with auto-trace for tokens that start getting traction.

**Architecture:** PumpPortal websocket (free create + migration events) feeds a `FeedService` in `apps/api` that stores tokens in SQLite `feed_tokens`, polls bonding curves with `getMultipleAccounts`, and queues low-priority auto-traces through the existing `JobManager`. The web app polls `GET /api/feed` every 4 s.

**Tech Stack:** Node 24 global `WebSocket`, Fastify 5, better-sqlite3, Vitest, React 19 + TanStack Query/Router, Tailwind v4, Playwright.

Spec: `docs/superpowers/specs/2026-10-21-screener-design.md`.

## Global Constraints

- Free sources only: PumpPortal `subscribeNewToken` + `subscribeMigration`, public Solana RPC. No API keys.
- Only `pool === "pump"` events are ingested.
- Progress = `(1 − real_token_reserves / 793_100_000_000_000) × 100`, clamped 0–100, `complete` → 100.
- Market cap SOL = `virtual_quote / virtual_token × token_total_supply / 1e9`; zero reserves → `null`.
- Defaults: `FEED_POLL_SEC=20`, `AUTO_TRACE_MIN_PROGRESS=40`, `AUTO_TRACE_WINDOW_SEC=900`, `AUTO_TRACE_PER_HOUR=20`, `FEED_RETENTION_HOURS=24`, `FEED_ENABLED=true`.
- Auto jobs: at most 1 running; user jobs always served first.
- No new npm dependencies.
- Code style: match existing files (no semicolon-free, 2-space, double quotes, short doc comments only where non-obvious).

```ts
export function curveMetrics(s: BondingCurveState): CurveMetrics {
  const realSol = Number(s.realQuoteReserves) / 1e9;
  if (s.complete) return { marketCapSol: null, progressPct: 100, realSol, complete: true };
  const sold = 1 - Number(s.realTokenReserves) / Number(INITIAL_REAL_TOKEN_RESERVES);
  const progressPct = Math.min(100, Math.max(0, sold * 100));
  const marketCapSol = s.virtualTokenReserves === 0n ? null
    : (Number(s.virtualQuoteReserves) / Number(s.virtualTokenReserves)) * (Number(s.tokenTotalSupply) / 1e9);
  return { marketCapSol, progressPct, realSol, complete: false };
}
```
  Note: price in SOL per raw token is `vq/vt` (lamports per raw unit, both scaled by 1e9 and 1e6 respectively); `× supply_raw / 1e9` gives SOL. Zero reserves and `!complete` (event-only rows) is handled by `vt === 0n`.
- [ ] Step 4: Tests pass; `pnpm --filter @pumpfun/core typecheck`.

```ts
// feed.ts
export interface FeedTokenInput { mint: string; name: string | null; symbol: string | null; uri: string | null; creator: string;
  bondingCurve: string; createSignature: string | null; createdAt: number; initialBuySol: number | null; isMayhemMode: boolean;

```
Schema:
```sql
CREATE TABLE IF NOT EXISTS feed_tokens (
  mint TEXT PRIMARY KEY, name TEXT, symbol TEXT, symbol_key TEXT, uri TEXT, creator TEXT NOT NULL,
  bonding_curve TEXT NOT NULL, create_signature TEXT, created_at INTEGER NOT NULL, initial_buy_sol REAL,
  mayhem INTEGER NOT NULL DEFAULT 0, market_cap_sol REAL, progress_pct REAL NOT NULL DEFAULT 0, real_sol REAL NOT NULL DEFAULT 0,
  complete INTEGER NOT NULL DEFAULT 0, migrated_at INTEGER, auto_traced_at INTEGER, polled_at INTEGER
);
CREATE INDEX IF NOT EXISTS feed_tokens_created ON feed_tokens(created_at);
CREATE INDEX IF NOT EXISTS feed_tokens_symbol ON feed_tokens(symbol_key, created_at);
CREATE INDEX IF NOT EXISTS feed_tokens_progress ON feed_tokens(progress_pct);
```
Rules:
- Poll set: `complete = 0 AND (created_at > now-600 OR (progress_pct >= 10 AND created_at > now-21600 AND (polled_at IS NULL OR polled_at <= now-120)))`, newest first, limit 1000.
- Candidates: `complete`-agnostic, `auto_traced_at IS NULL`, `created_at > now-windowSec`, `progress_pct >= min`, and no `trace_results` row with `finished_at > now-3600`; order `progress_pct DESC`, limit 50.
- `feed`: LEFT JOIN `trace_results` for `score`, level via `json_extract(json,'$.score.level')`, `finished_at AS tracedAt`. Copycat = correlated count on `symbol_key` within `created_at > now-86400`, excluding self (0 when `symbol_key` is null/empty).
  - `new`: `ORDER BY created_at DESC`
  - `hot`: `WHERE migrated_at IS NULL AND complete = 0 AND created_at > now-21600 ORDER BY progress_pct DESC`
  - `traced`: `WHERE tr.mint IS NOT NULL ORDER BY tr.finished_at DESC`
  - `hideHigh`: `AND (level IS NULL OR level != 'high')`
- Stats: `seenLastHour` = rows with `created_at > now-3600`; `tracedLastHour` = feed rows joined to results with `finished_at > now-3600`; `highRiskShare` = high/traced among those, null when 0.
- `findCreateSignature`: trace_results first, then `feed_tokens.create_signature`.
