# Socials, Dev Habits, Risky Wallets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Token socials with recycled-socials detection, a dev habit profile, and a neutral Risky Wallets page.

**Architecture:** Pure parsing/profiling in `packages/core` behind a new `MetadataSource` interface; an SSRF-safe HTTP fetcher with IPFS gateway rewriting in `apps/api` feeds a `token_meta` table from both the live feed and traces; SQLite queries power reuse checks and the risky lists.

**Tech Stack:** Node 24 (`node:http`/`node:https` with custom `lookup`), better-sqlite3, Fastify 5, React 19, Vitest, Playwright.

Spec: `docs/superpowers/specs/2026-10-22-insights-design.md`.

## Global Constraints

- No new npm dependencies; no paid APIs.
- Fetcher: only `http:`/`https:`, reject private/loopback/link-local/CGNAT/multicast IPs (v4 and v6) at DNS lookup, ≤ 2 redirects re-checked, 5 s timeout, 64 KB cap, JSON only.
- IPFS: `https://ipfs.filebase.io/ipfs/<CID>` first, `https://4everland.io/ipfs/<CID>` fallback.
- Reuse counts only tokens created ≥ 3600 s earlier; twitter reuse only between `kind: "account"` links.
- Weights: `recycledSocials` 15, `fastSeller` 15 (`fastSells ≥ 2`, sold ≤ 10 min after launch).
- UI renders only http(s) links with `rel="noopener noreferrer nofollow"`. Copy for risky page is factual and neutral ("Risky wallets").
- Old stored results without `socials`/`devProfile` must still render (treat as null).

Tests: `gatewayUrls` (ipfs://, ipfs.io, pinata subdomain, plain https untouched, non-http → []); `isPublicAddress` (10/8, 127/8, 169.254/16, 172.16/12, 192.168/16, 100.64/10, 0/8, ::1, fc00::/7, fe80::/10, ::ffff:127.0.0.1 → false; 8.8.8.8, 2606:4700::1 → true); fetcher against a local `http.createServer` with injected lookup that maps a test hostname to 127.0.0.1 only when allowed: JSON ok; private address refused; redirect to blocked host refused; >64 KB refused; non-JSON refused; timeout. Commit: `feat(api): SSRF-safe metadata fetcher with IPFS gateways`.
